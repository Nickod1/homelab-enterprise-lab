# homelab-enterprise-lab
Enterprise-style home lab featuring Proxmox, pfSense, Active Directory, Windows Server, and network segmentation for hands-on infrastructure, networking, and security practice.

# <h1>My Home Lab Infrastructure</h1>

<h2>Overview</h2>
This repository documents my enterprise-style home lab environment built to simulate a real-world IT infrastructure for learning, testing, and hands-on experience with enterprise technologies.

<br>The environment is designed to strengthen practical skills in:
<ul> <li>Virtualization</li>
<li>Enterprise networking</li>
<li>Active Directory administration</li>
<li>Windows & Linux system administration</li>
<li>Network security and segmentation</li>
<li>Firewall management</li>
<li>Infrastructure troubleshooting</li>
<li>Enterprise architecture design</li>
</ul>

This lab is continuously evolving as I expand into cloud, security, monitoring, automation, and hybrid infrastructure technologies.
<br />


<h2>Infrastructure Stack</h2>
<pre>
| Category                 | Technology                       |
| ------------------------ | -------------------------------- |
| Hypervisor               | Proxmox VE                       |
| Firewall / Router        | pfSense                          |
| Switching                | Ubiquiti                         |
| Virtualization Cluster   | 2-node Proxmox cluster           |
| Server OS                | Windows Server 2025              |
| Client Operating Systems | Windows & Linux                  |
| Identity Services        | Active Directory Domain Services |
| Network Design           | Segmented home and lab networks  |
| Authentication           | Domain-based authentication      |
| Remote Administration    | RDP, SSH, Web Management         |
---------------------------------------------------------------
</pre>

<h2>Lab Objectives</h2>
<ul> <li>Simulate an enterprise-grade infrastructure environment</li>
<li>Practice Windows Server administration and Active Directory management</li>
<li>Gain hands-on experience with virtualization and clustering technologies</li>
<li>Implement secure network segmentation using firewall policies</li>
<li>Test interoperability between Windows and Linux systems</li>
<li>Develop infrastructure documentation and troubleshooting workflows</li>
<li>Build practical experience relevant to cloud, infrastructure, and security roles</li>
</ul>
